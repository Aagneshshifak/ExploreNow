Build a complete backend for a travel booking platform called **ExploreNow** using **Express.js**, **Prisma ORM**, **JWT authentication**, and a **PostgreSQL database (Neon)**.

🔧 Requirements:

1. 📁 File Structure:
- `server/index.ts` → Express server entrypoint
- `server/routes.ts` → Combine all routes here
- `server/controllers/` → Separate files for trips, hotels, bookings, auth, admin
- `server/middlewares/` → For auth, error handling
- `server/db.ts` → Prisma client setup
- `prisma/schema.prisma` → Prisma schema for DB models
- `.env` → Environment variables

2. 🔐 Authentication:
- Register: `POST /api/auth/register`
- Login: `POST /api/auth/login`
- Hash passwords with bcrypt
- Use JWT for session management (stored in cookies)
- Middleware to protect routes using JWT
- Admin/user roles

3. 📦 Trips:
- `GET /api/trips` → List all trips
- `POST /api/trips` → Add a new trip
- `PUT /api/trips/:id` → Edit a trip
- `DELETE /api/trips/:id` → Delete a trip

4. 🏨 Hotels:
- `GET /api/hotels`
- `POST /api/hotels`
- `PUT /api/hotels/:id`
- `DELETE /api/hotels/:id`

5. 🧾 Bookings:
- `POST /api/bookings/trip/:tripId`
- `POST /api/bookings/hotel/:hotelId`
- `GET /api/bookings` → View user’s bookings

6. 📊 Admin:
- `GET /api/admin/analytics` → Return total trips, total hotels, total bookings

7. 🌐 Config:
- Enable CORS for frontend (on Vercel)
- Use dotenv for environment config
- Connect to Neon PostgreSQL DB using `DATABASE_URL`
- Include `PORT`, `JWT_SECRET` in `.env`

8. ✍️ Prisma Models (schema.prisma):
- `User` (id, name, email, password, role, bookings)
- `Trip` (id, title, location, price, imageUrl, etc.)
- `Hotel` (id, name, location, price, imageUrl, etc.)
- `Booking` (id, userId, tripId?, hotelId?, type, createdAt)

9. 📁 Output:
- Provide complete source code for all required files
- Ensure `npm run dev` works (use tsx or nodemon)
- Prisma should use the default path: `prisma/schema.prisma`
- Seed DB with sample trips and hotels
- Keep everything TypeScript-based

I want to deploy this backend on Replit and test it from my Vercel frontend via `VITE_API_URL`.
