Build a full-stack travel booking platform named **ExploreNow** using:

**Frontend**: React + Tailwind + Vite  
**Backend**: Express + TypeScript  
**Database**: PostgreSQL using **Drizzle ORM**  
**Hosting**: Frontend on Vercel, backend on Render/Fly.io, database on Neon

---

✅ FEATURES TO IMPLEMENT (ALL DONE)

1. **Authentication**
   - JWT-based Auth with refresh token
   - Role-based login: user, admin
   - Auth guards for routes and frontend pages
   - Admin-only access to admin dashboard and trip/hotel update routes

2. **Trips & Hotels**
   - GET /trips and /hotels (filtered, paginated)
   - POST /trips and /hotels (admin only)
   - PATCH /trips/:id and /hotels/:id (admin only)
   - Store: title, desc, price, location, images, date, ratings, etc.

3. **Booking System**
   - POST /bookings (user can book trip or hotel)
   - Each booking stores: userId, tripId/hotelId, timestamp
   - Prevent duplicate bookings (optional)
   - User can view their bookings
   - Admin can view all bookings

4. **Currency Converter**
   - Real-time currency conversion integrated in:
     - Home → Featured Trips
     - Hotels page
     - Booking page
   - Uses public exchange rate API (e.g., exchangerate.host)

5. **Drizzle ORM**
   - All tables and relations built with Drizzle
   - Verified types, strict schemas
   - Full LSP/type safety and working CRUD
   - Tables: users, trips, hotels, bookings

6. **Admin Dashboard**
   - View total trips, hotels, bookings
   - Manage trips/hotels (update, remove)
   - Access restricted to admin role only
